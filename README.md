# myridia

Hi friend 👋

Myridia is a small software company I'm building one commit at a time. Right now it is a one-man show: me, too many open tabs, and a few AI agents helping with the boring bits. The hierarchy is simple — one human, some bots, no drama.

We care about Free Software, Free Money, Free Land, Free Market and Free Humans. We also like building small, useful tools and learning how technology changes the world around us.

## Developers, come say hi

If you are a developer who wants to build things with us, you are invited. Come as you are — and yes, bring your AI. I do not mind if you write code with Copilot, ChatGPT, Claude, OpenCode, a local model, or a very patient rubber duck. Use whatever helps you think. The only request is that you still read the code, care about the people using it, and laugh when an agent confidently suggests something ridiculous.

What this looks like in practice:

- Real projects, real users, and very few meetings
- A tiny team where your work is actually visible
- Room to experiment and say "let's try it"
- AI agents for the boring bits, humans for the interesting bits
- A direct line to the human running the show

So if you want a friendlier place to build things — with AI or without it — send a note to **info@myridia.com**. Tell me what you like to make, what tools you use, and what your favourite questionable emoji is.

- 📫 How to reach us: info@myridia.com
- 😄 Pronouns: We — close enough
- ⚡ Fun fact: AI will not conquer the world, it's just our latest trickster
